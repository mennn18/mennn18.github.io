NGOPI WEB — Static storefront for GitHub Pages

Isi paket:
- index.html: landing page/katalog statis untuk Ngopi Web.

Teknologi yang digunakan:
- HTML, CSS, JavaScript biasa (tanpa framework/build tools).
- Cocok untuk GitHub Pages karena tidak memerlukan backend.

Sebelum dipublikasikan:
1. Buka index.html dengan editor kode.
2. Cari baris: const WHATSAPP_NUMBER = "628XXXXXXXXXX";
3. Ganti dengan nomor WhatsApp aktif milikmu, format internasional tanpa +, spasi, atau tanda hubung.
   Contoh format Indonesia: 6281234567890.
4. Periksa nama produk, deskripsi, harga contoh, dan lisensi. Ganti harga contoh sesuai harga jual sebenarnya.
5. Tombol "Tanya Demo" saat ini menghubungi WhatsApp; ganti dengan tautan demo sebenarnya jika demo produk sudah tersedia.
6. Simpan dan uji secara lokal di browser.

Cara memasang ke GitHub Pages:
1. Cadangkan index.html lama terlebih dahulu.
2. Buka repo https://github.com/mennn18/mennn18.github.io
3. Pilih Add file > Upload files.
4. Upload index.html baru dan pilih untuk mengganti file yang ada.
5. Commit changes ke branch yang dipakai GitHub Pages (biasanya main).
6. Tunggu publikasi, lalu uji https://ngopi-web.my.id

Catatan:
- Domain/CNAME tidak perlu dihapus. Pertahankan file CNAME yang sudah berisi ngopi-web.my.id.
- Ini adalah katalog statis. Belum ada dashboard admin, database, keranjang, checkout otomatis, atau pembayaran otomatis.
- Jangan menjual source code yang bukan milikmu atau yang tidak kamu punya hak distribusinya.
